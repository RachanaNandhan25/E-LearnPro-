
               E-LearnPro - Online Learning Management System

OVERVIEW

E-LearnPro is a responsive and user-centric Learning Management System (LMS) designed to offer seamless user registration, login, course enrolment, and content interaction. This project involved full-cycle development using HTML, CSS, JavaScript, jQuery, Unix shell scripting, and Git, with Agile project management in Jira.

1.  User Stories & Sprint Setup (Jira)
   
    •	Created user stories for registration and login with clear scope and acceptance criteria.
    
    •	Maintained the product backlog in Jira, organized into epics, user stories, and tasks.
    
    •	Set up Jira Sprint Board with defined sprint duration, goals, and task tracking across workflow stages.
    
2.  Shell Scripting for LMS Monitoring
   
      •	Wrote a modular shell script lms_monitor.sh to monitor the LMS folder.
    
      •	Automated backup creation using tar archives with timestamps.
    
      •	Maintained a detailed log of changes and supported configurable paths and intervals.
    
      •	Technologies: bash, tar, find, diff, mkdir, cron.
    
3.  HTML Responsive Pages (Login & Registration)
   
         •	Built a combined login/sign-up interface in index.html using HTML, CSS, and Bootstrap.
    
         •	Designed registration.html with all required fields for course enrollment.
    
         •	Ensured layout alignment, responsiveness, and mobile compatibility.
    
4. JavaScript & jQuery Form Validation
   
            •	Implemented client-side validation using JavaScript and jQuery
   
            o	Email format check
   
            o	Password strength & match
   
            o	Toggle password visibility
   
            o	Real-time feedback and redirection on success
   
            •	Prevented invalid form submissions and improved overall UX.
   
5. UI/UX Validation & QA Testing
    
                    •	Created and executed a UI/UX Validation Checklist (checklist.xlsx).
    
                    •	Tested:
    
                            o	Form field validations
    
                            o	Button/link behavior
    
                            o	Navigation consistency
    
                            o	Error handling
    
                            o	Accessibility
    
                            •	Ensured compatibility across devices and browsers.
    
                            •	Involved QA in design iterations to improve mid-sprint design clarity.
    
6. Git Workflow Implementation
    
                  •	Initialized Git repository and set up branching model
    
                  o	main: Production-ready code
    
                  o	develop: Integration branch
    
                  o	feature/*: Specific features (e.g., feature/signup-form)
